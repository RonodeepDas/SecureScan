# SecureScan

SecureScan is a local-first security toolkit for checking password strength and performing authorized port scans. It combines a browser-only password analyzer with a FastAPI backend that stores encrypted history and validates scan requests before running any network probes.

Live project repo: https://github.com/RonodeepDas/SecureScan

## Features

- Password strength estimation using zxcvbn entirely in the browser
- No password transmission to the backend
- Encrypted metadata storage with AES-256-GCM
- FastAPI backend with HTTPS support for local development
- Authorization gate for port scanning requests
- Per-port timeout and concurrency control
- Rate limiting and log scrubbing for safer local use
- SQLite-backed encrypted history for both password and scan results

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Python, FastAPI, SQLAlchemy
- Security: AES-256-GCM, TLS self-signed dev certificates, rate limiting
- Storage: SQLite

## Prerequisites

- Python 3.11+
- Node.js 18+
- OpenSSL (for generating local certificates)

## Backend Setup

```bash
cd backend
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
# source .venv/bin/activate

pip install -r requirements.txt
```

Create a local environment file:

```bash
copy .env.example .env
```

Generate a 32-byte AES key and paste it into `.env`:

```bash
python -c "import os, binascii; print(binascii.hexlify(os.urandom(32)).decode())"
```

Then start the API:

```bash
python main.py
```

The backend auto-generates a self-signed TLS cert on first run. Open the app using HTTPS and accept the browser warning for local development.

API docs: https://localhost:8000/docs

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Open:

- https://localhost:5173

The frontend dev server proxies `/api/*` requests to the backend.

## Verification

The project includes automated tests for:

- encryption round-trips and tamper detection
- input validation and hostname rejection
- scan authorization gate and port-cap enforcement
- ORM round-trips for encrypted history records

Run:

```bash
cd backend
pytest tests/ -v
```

Run a frontend build check:

```bash
cd frontend
npm run build
```

## Security Notes

- Passwords are analyzed entirely in the browser and never sent to the backend.
- Only score, crack-time estimate, and timestamp metadata are stored.
- Port scanning is blocked unless the user explicitly confirms authorization.
- The backend rejects invalid targets and enforces a 1024-port cap.
- History is encrypted at rest with AES-256-GCM.
- This project is intended for local authorized testing only.

## Legal / Responsible Use

SecureScan is designed for ethical, authorized security testing on systems you own or have explicit written permission to evaluate.

Never run port scans against systems without authorization.
